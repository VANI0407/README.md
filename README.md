# VDF Bank ATM
### Secure. Simple. Instant. — Banking at Your Fingertips.
# Overview 
VDF Bank ATM is a Python-based console application designed to simulate the basic operations of an Automated Teller Machine (ATM). The project provides users with a simple and interactive interface to perform common banking operations such as PIN verification, checking account balance, depositing money, and withdrawing money.
The application is developed using fundamental Python programming concepts such as functions, loops, conditional statements, variables, and user input. It is designed as an educational project to demonstrate how programming concepts can be applied to a real-world banking scenario.
The system provides a simple and user-friendly ATM experience while focusing on basic transaction logic and input validation.
# Features 
* PIN verification
* Check account balance
* Deposit money
* Withdraw money
* Insufficient balance checking
* Menu-driven interface
* Invalid choice handling
* Secure exit option
